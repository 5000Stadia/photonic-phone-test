# Photonic phone test

A frame-time test for Photonic, the people engine of the holodeck project. It draws 300 stand-in bodies walking, every one a different shape, in one draw call (three.js r186, WebGPU with a WebGL2 fallback).

Open it at https://5000stadia.github.io/photonic-phone-test/. Settings ride in the hash: `#c3t-300`, `#c3t-1000`, `#c1-300`, and `-gl` forces WebGL2.
